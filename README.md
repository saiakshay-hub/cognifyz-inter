# Train Data Analysis Project

This project focuses on analyzing railway train data using Python and Pandas. The workflow includes:

- Data Cleaning
- Handling Missing Values
- Standardizing Station Names
- Feature Engineering
- Aggregation and Grouping
- Train Traffic Analysis
- Data Visualization
- ETL Pipeline Concepts

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Learning Outcomes
- Data Preprocessing
- Exploratory Data Analysis (EDA)
- Data Engineering Fundamentals
- Feature Engineering
- Data Visualization
